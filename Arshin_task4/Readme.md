## Task 4 - CSS Units, Box Model, Fonts ##

# Project Description
This project demonstrates the use of CSS units, box model properties, viewport units, fonts, borders, and gradient backgrounds.

The webpage contains a centered section with an image and a "Click Me" button. The image and button are placed inside a common bordered container.

# Files Included

- index.html - Contains the HTML structure of the webpage.
- style.css - Contains all the CSS styling.
- Readme.md - Contains the project information and requirements.

# Features
~ HTML Setup

    - Created a proper HTML5 document structure.
    - Added a webpage title "Task 4 - CSS Units, Box Model, Fonts".
    - Linked an external CSS file using `<link>`.
~Body Content

    - Created a section for displaying the content.
    - Created a `div` container for the image and button.
    - Added an image using an external image URL.
    - Added a button with the text "Click Me".
~CSS Styling

    - Used viewport units such as `vw` and `vh`.
    - The main section has equal spacing of `25vw` from the left and right.
    - The main section has `10vh` spacing from the top and bottom.
    -container is 50vw * 80vh (width->25+25=50 100-50=50 height->10+10=20 100-20=80)
    - Used `box-sizing: border-box`.
    - Used a gradient background for the button.
    - Added font styling to the button.
    - Added a hover effect to the button.
    - Used `object-fit: cover` for the image.
