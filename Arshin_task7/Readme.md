
# Task 7 - CSS Responsive Issues

A simple and responsive Laundry Mart Service Webpage built using HTML and CSS. The project demonstrates the use of Flexbox, responsive media queries, CSS styling, and responsive layouts to create a webpage that adapts to different screen sizes.

## Project Overview

This project is a frontend landing page for a fictional laundry service called Laundry Service.

The page includes:

    -Navigation links
    -Username button
    -Laundry service logo
    -Hero section
    -Main heading and service description
    -"Book a Service Today" call-to-action button
    -Laundry-related image
    -Responsive design for tablets and mobile devices
    -A navigation bar

## Technologies Used

- HTML5 – Used to create the structure of the webpage.
- CSS3 – Used for styling, layout, Flexbox, and responsive design.
- Media Queries – Used to make the website responsive on different screen sizes.

## Project Structure

## Responsive Design

The project uses CSS media queries to adapt the layout to different screen sizes.

1) Tablet / Smaller Screens

For screens below 770px, the design adjusts:

    -Navbar height
    -Button sizes
    -Heading sizes
    -Left-section padding
    -Booking button dimensions

2) Mobile Screens

For screens below 380px, the layout changes significantly:

    -Navigation links are hidden
    -Hero section changes from row to column
    -Text content becomes wider
    -Booking button becomes mobile-friendly
    -Image width is adjusted

## Main Feature
