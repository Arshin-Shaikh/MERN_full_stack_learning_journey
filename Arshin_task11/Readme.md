# Thala7 Sneakers Store

## CSS Mini Project — Online Sneaker Shopping Website

Thala7 Sneakers Store is a sneaker shopping website built using HTML5 and CSS3.
The project focuses on web page structure, styling, layout design, and creating a clean e-commerce user interface.

## Project Overview

The website provides a product shopping experience with a navigation bar, featured sneaker section, product details, shopping cart, order summary, and checkout form.

It uses a combination of HTML for structure and CSS for styling, with Font Awesome icons and Google Fonts to enhance the visual appearance.

## Features

1. Navigation Bar
   - Website logo featuring the Thala7 brand.
   - Navigation links for Home, About, Products, More, and Contact.
   - Search bar with a search icon.
   - Shopping cart icon and user profile icon.
   - Fixed navigation bar for easy access to navigation links.

2. Hero Section
   - Eye-catching promotional section featuring the Thala7 theme.
   - Promotional heading: "7!! Thala for a Reason!"
   - Short introduction to the sneaker collection.
   - Shop Now button for navigating to the product section.

3. Statistics Section
   Displays store statistics and highlights, including:
   - 2K+ Reviews.
   - 30K+ Customers.
   - High Quality.
   - 4.5/5 Rating.

4. Product Details Section
   - Featured sneaker product display.
   - Product image with hover effect.
   - Product name and description.
   - Star rating and review count.
   - Original price and discounted price.
   - Discount percentage and tax information.
   - Quantity selection dropdown.
   - Add to Cart button.
   - Horizontal gallery of related sneaker images.

5. Shopping Cart
   - Shopping cart table displaying products.
   - Product images, names, categories, and prices.
   - Quantity increase and decrease controls in the interface.
   - Remove product buttons.
   - Continue Shopping link.
   - Order summary displaying subtotal, taxes, discount, and total.
   - Coupon code input field.
   - Pay Now button.
   - Payment security information and Razorpay branding.

6. Checkout Section
   - Customer email input field.
   - Payment method selection interface.
   - Card number, expiry date, and CVV fields.
   - Country selection dropdown.
   - ZIP/PIN code input field.
   - Coupon code input field.
   - Order price summary.
   - Pay Now button.
   - Payment security indicators.

7. UI and Styling
   - Clean and modern e-commerce layout.
   - Orange, blue, white, and neutral color palette.
   - Flexbox and CSS Grid layouts.
   - Hover effects and smooth scrolling.
   - Google Fonts typography.
   - Font Awesome icons.
   - Product image styling and interactive visual elements.

## Technologies Used

- HTML5 - Structure and content of the website
- CSS3 - Styling, layouts, colors, and visual effects
- Google Fonts - Custom typography
- Font Awesome - Navigation, shopping, rating, and payment icons
- Unsplash Images - Sneaker product images

## Conclusion

Built as a front-end web development mini project to practice HTML and CSS through an e-commerce sneaker store design.
