# Task 5 - Laundary Service Hero Section

This project is a simple laundry service website hero section created using **HTML and CSS**.

The main objective of this task is to practice CSS properties such as `display`, `position`, `float`, `clear`, `overflow`, and `z-index` without using Flexbox.

# Project Description-
The webpage represents a laundry service called **Laundry Services**.

It contains:

- A navigation bar
- A logo image
- Navigation links
- Username section
- A hero section
- Laundry service heading and description
- "Book a service today!" button
- Laundry-related image
-Used google font lato for the text 

# Technologies Used

- HTML5
- CSS3
