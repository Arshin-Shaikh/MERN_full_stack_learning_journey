# JavaScript Promise Division

A simple JavaScript program that divides two numbers using a Promise and handles division-by-zero errors.

## Features

- Uses an arrow function.
- Returns a Promise from the division function.
- Resolves the Promise with the division result when the divisor is non-zero.
- Rejects the Promise with a meaningful error message when the divisor is zero.
- Handles resolved and rejected Promises using .then() and .catch().
- Includes five test cases.

## Output

Dividing 10 by 2...
Result: 5
Dividing 20 by 4...
Result: 5
Dividing 15 by 3...
Result: 5
Dividing 7 by 2...
Result: 3.5
Dividing 10 by 0...
Error: Division by zero is not allowed.

## Concepts Demonstrated

- JavaScript arrow functions
- Promises (resolve and reject)
- Error handling with .catch()
- Asynchronous execution
