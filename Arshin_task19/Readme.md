# Laundry Booking Services – Mini Project

## Project Overview

The Laundry Booking Services project is a simple and responsive web application developed using HTML, CSS, and JavaScript. It allows users to browse different laundry services, add their preferred services to a shopping cart, view the total amount, and proceed to checkout.

The main objective of this project is to understand and implement JavaScript DOM manipulation, event handling, arrays, and basic form validation in a real-world application.

## Features

    - Responsive Navigation Bar: Easy navigation with Home, Services, About Us, and Contact Us links.

    - Browse Laundry Services: View different laundry services with images and prices.

    - Skip Item: Navigate through available laundry services.

    - Add to Cart: Add selected laundry services to the cart.

    - Shopping Cart: Display selected services in a table with serial numbers and prices.

    - Total Amount Calculation: Automatically calculate the total cost of selected services.

    - Booking Form: Collect customer details, including name, email, and phone number.

    - Form Validation: Validate required fields, email format, and 10-digit phone number.

    - Checkout Page: Display a booking confirmation message after successful form submission.

## Technologies Used

    - HTML5 – Structure of the web application.

    - CSS3 – Styling, layout, and responsive design.

    - JavaScript – DOM manipulation, event handling, cart management, and form validation.

    - Font Awesome – Icons used in the user interface.

## JavaScript Concepts Implemented

This project demonstrates the following JavaScript concepts:

    - document.querySelector() and document.getElementById()

    - DOM element creation using document.createElement()

    - DOM manipulation using innerHTML and textContent

    - Event listeners using addEventListener()

    - Arrays and objects for storing service information

    - Array methods such as forEach()

    - Dynamic HTML content rendering

    - Cart management using arrays

    - Total price calculation using loops

    - Form validation using checkValidity()

    - Page navigation using window.location.href

## Learning Objectives

The purpose of this mini project is to gain practical knowledge of:

    - Building web pages using HTML5.

    - Applying CSS styling and responsive layouts.

    - Understanding JavaScript DOM manipulation.

    - Handling user interactions through events.

    - Dynamically displaying data on a webpage.

    - Managing cart items and calculating totals.

    - Implementing basic client-side form validation.
