# Laundry Mart Login Page

A simple and responsive **Laundry Mart Login Page** created using **HTML and CSS Flexbox**.

## Project Description

This project is a login page with a split-screen layout. The left side contains a laundry-related image, while the right side contains a login form.

The main purpose of this project is to practice basic CSS properties and understand how to create layouts using **Flexbox**.

## features
    -Split-screen login page design
    -CSS Flexbox used for alignment and positioning(centered)
    -Laundry-themed image section(left-section)
    -Email input field with placeholder
    -Password input field with placeholder
    -Forgot Password link
    -Log in button with hover effect
    -Register Now link for new users
    -Clean and user-friendly interface
    -Centered content using Flexbox
    -Simple and attractive color scheme
    -No Bootstrap or external CSS framework used

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
