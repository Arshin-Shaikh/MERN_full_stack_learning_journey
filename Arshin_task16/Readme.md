# Javascript map filter Project

A simple and responsive Student Records Management web application built using HTML, CSS, and JavaScript. This project allows users to view student details and search for students by name using JavaScript's filter() and map() methods.

## Project Overview

The Student Records application displays student information in a clean card-based layout. Users can search for a particular student by entering their name in the search bar. The application filters the student records dynamically and displays only the matching results.

This project demonstrates the practical use of JavaScript array methods, DOM manipulation, event listeners, and responsive CSS layouts.

## Features

- Student Records Display: Displays student names, marks, classes, and addresses.
- Search Functionality: Search for students by name.
- Dynamic Filtering: Automatically filters student records as the user types.
- Case-Insensitive Search: Search works regardless of uppercase or lowercase letters.
- Search Button: Filter student records by clicking the search button.
- No Results Message: Displays a message when no students match the search query.
- Responsive Layout: Organizes student cards into a grid layout for different screen sizes.
- Clean User Interface: Simple and user-friendly design.

## Technologies Used

- HTML5 — Structures the web page and student records section.
- CSS3 — Styles the application, student cards, search bar, and layout.
- JavaScript (ES6+) — Implements search functionality, array filtering, and dynamic rendering.
- Font Awesome — Provides the search icon.
- Google Fonts — Enhances the typography.
