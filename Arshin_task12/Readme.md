# Compound Interest Calculator

## Project Description

The Compound Interest Calculator is a simple JavaScript project that calculates the compound interest and the total amount based on the principal amount, annual interest rate, compounding frequency, and time period.

This project uses JavaScript's prompt() function to take input from the user and console.log() to display the results.

## Features

    - Calculates compound interest using JavaScript.
    - Calculates the total amount after compound interest.
    - Accepts user input through prompt().
    - Displays results in the browser console using console.log().
    - Simple and attractive user interface using HTML and CSS.
    - Responsive design for different screen sizes.
    - Animated calculator image using CSS keyframes.

## Technologies Used

    - HTML5 — Structures the webpage.
    - CSS3 — Styles the webpage and creates the image animation.
    - JavaScript — Accepts user input and calculates compound interest.

## Learning Objectives

    - Understanding JavaScript variables.
    - Taking user input using prompt().
    - Converting strings to numbers using Number().
    - Performing mathematical calculations using the exponentiation operator (**).
    - Formatting numerical results using toFixed(2).
    - Displaying output using console.log().

## Formula

The formula for calculating compound interest is:

A = P × (1 + R / (100 × N)) ^ (N × T)

CI = A − P

Where:

    - A = Final amount
    - P = Principal amount
    - R = Annual rate of interest (percentage)
    - N = Number of times interest is compounded per year
    - T = Time period in years
    - CI = Compound interest

## Example

Input:

Principal (P): 10000
Rate of Interest (R): 5
Compounding Frequency (N): 4
Time (T): 2

Output:

Compound amount after 2 years is 11044.86
Compound interest after 2 years is 1044.86
